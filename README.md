# Glibi Game Launcher (Electron)

Modern, minimalist ve yüksek performanslı oyun başlatıcısı projesi (Electron tabanlı).

## Tasarım Özellikleri
- **Renk Teması:** Saf `#1c1c1c` minimalist koyu tema.
- **Pencere:** Çerçevesiz (`frameless`), özel sürükleme alanı ve pencere kontrol butonları (`―`, `□`, `✕`).
- **Animasyonsuz Tasarım:** Üzerine gelindiğinde (hover) kafa karıştırıcı ve dikkat dağıtıcı animasyonlar kapalıdır (`transition: none !important; transform: none !important;`).
- **Mockup Oyunlar:** Cyberpunk 2077, Elden Ring, The Witcher 3, Red Dead Redemption II, Hades II, God of War Ragnarök, Minecraft, Baldur's Gate 3 için özel yüksek kaliteli poster kapakları.

cd /home/qlat/Dev/Glibi
